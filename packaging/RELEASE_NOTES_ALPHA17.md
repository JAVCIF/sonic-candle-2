# Sonic Candle 2.0 Alpha 17

This is the first public Alpha 17 release of the Java continuation of Sonic Candle.

## Downloads

- **Windows EXE:** self-contained installer with a private Java runtime. FFmpeg and FFprobe must be installed separately or available in `PATH`.
- **Executable JAR:** cross-platform Java package. Requires JDK/JRE 17 or newer plus FFmpeg and FFprobe.

## Highlights

- Bars, Circular, Dual bar, and Loading bar visualizers.
- English and Spanish interface.
- Modern and Classic themes.
- Synchronized audiovisual preview with timeline seeking.
- MP4, ProRes 4444, WebM VP9, and PNG-sequence export.
- Transparent video output with Circular fill preservation.
- Frequency-distribution and motion-response modes.
- Rotating diagnostic logs and theme-aware dialogs.

This is an alpha release. Please report reproducible problems through the repository's bug-report form and attach the relevant diagnostic log when possible.
