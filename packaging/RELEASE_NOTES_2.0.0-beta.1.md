# Sonic Candle 2.0 Beta 1.0

Beta 1.0 is the first release intended for broad community testing. It freezes the complete Alpha 20 feature set while feedback, compatibility reports, bug reports, and future preset ideas are collected.

## What's included

- Six visualizer modes: Bars, Circular, Dual bar, Loading bar, Cardiogram, and the new Neon Wave.
- Real-time audiovisual preview with Play/Pause, audio playback, and timeline seeking.
- Audio or video input, including videos with embedded audio and silent background videos paired with a separate song.
- Color, image, and streamed-video backgrounds with Cover, Contain, Stretch, Loop, and Freeze controls.
- MP4, transparent ProRes 4444, transparent WebM VP9, and transparent PNG-sequence exports.
- Spanish and English interfaces plus Modern blue and Classic themes.
- Rotating diagnostic logs for actionable bug reports.

## New in the Beta candidate

Neon Wave turns the spectrum into a contained polygonal trace with 8–32 glowing nodes, temporal echoes, music-driven deterministic particles, three line finishes, adjustable glow, top/center/bottom placement, and vertical inversion. Its straight node line remains visible during absolute silence.

The preceding Alpha 18 and Alpha 19 work is also included: streamed video backgrounds, automatic media-track detection, embedded-cover filtering, and the adaptive Cardiogram visualizer.

## Downloads

- **Windows EXE:** includes a private Java runtime. FFmpeg and FFprobe must still be available in `PATH` or bundled beside the application.
- **Executable JAR:** requires Java 17 or newer plus FFmpeg and FFprobe.

Please include your operating system, Java and FFmpeg versions, input/output formats, visualizer configuration, reproduction steps, and the newest file from `logs/` when reporting a problem.
